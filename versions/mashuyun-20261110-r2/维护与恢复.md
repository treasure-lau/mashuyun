# 维护与恢复

接入中断时，保留原安装目录、原用户、原节点身份和原向导状态，重新打开同一版接入助手继续。不要通过删除目录、重建身份或改写配置来处理未知结果。

## 接入向导中断

缺少依赖时，向导会保存草稿。补齐相同路径的依赖后，选择“继续检查原草稿”。关闭窗口或网络中断后重新打开助手，会接续登记、授权、安装和服务检查。

在原解包目录可用 `./mashuyun saas-setup --status` 只读查看向导状态，或用 `./mashuyun saas-setup --interactive` 继续。若开始时指定过私有状态目录，重试时继续使用同一个 `--state-dir`。

登记或授权提交超时不表示服务器一定没有接受。沿原身份重试；只有在原状态明确要求新登记码时，才在相同组织为相同职责重新生成。原文件节点已绑定时不能新建第二份文件绑定。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 平台无批准下载或所选平台能力不符 | 核对目标平台，稍后刷新接入信息；不要混装其他版本 |
| 自动授权服务或公钥未就绪 | 保留原进度，待平台恢复后刷新；不改为手工授权流程 |
| Mac 助手请求选择发布包 | 选择刚解压的完整麻树云文件夹，保持其中的工具与材料齐全，随后继续接入页面 |
| 授权申请被拒绝 | 读取具体原因，修复后在原节点申请中重试，保留原申请编号 |
| Docker 不可用或引擎身份不符 | 启动并检查原本机引擎，不切换远程 context，不删除原数据库 |
| Agent 在线但下载失败 | 检查下载域名、证书链、反向代理和实际下载网络，在线状态不能代替 HTTPS 验证 |
| 下载长度或 SHA256 不符 | 核对原文件与当前发布，排除代理替换、缓存或文件损坏，再重新验证 |
| 发布已变化 | 刷新并选择当前发布版本；旧结果仅作为历史记录 |
| 平台请求超时或返回未知结果 | 选择“重试原请求”，保留原编号和范围，不另建同类验证 |

保存业务验证范围或发起下载验证后，请等待原结果。页面重新打开时若显示原请求待确认，继续原请求；完整读取失败可按页面提示重新验证。历史成功记录不等于当前许可、连接、存储或发布仍有效。

## 证书与机器维护

监控磁盘余量、节点在线状态和授权到期提示。Mac 需要保持运行与 Docker 可用，机器重启或用户会话变化后，应检查原服务及真实下载入口。

证书换发保留原下载域名及节点身份，使用原受管节点的证书维护入口。已有网关模式在原网关维护证书；本机证书模式按当前版本工具帮助执行受管换发，并重新验证证书与下载。更改下载域名或迁移机器应使用相应受管流程，不能直接改地址或复制身份目录到另一台机器启动。

## 备份与升级

维护前保留原安装目录和独立备份，覆盖数据库、文件数据、节点身份及需要的本机私有材料。使用当前版本工具的检查点与校验能力，备份放在安装根之外，并独立保存检查点摘要；复制程序目录不能代替业务备份。

升级前先核验新交付包及兼容范围，按受管升级流程准备检查点和数据库检查，不手动替换容器镜像或二进制。恢复与回退使用当前受信工具及原记录；未确认恢复资格前不要启动恢复副本。不要在仍有写入或在途任务时强制清理数据。

自动续期沿原身份与期限合同运行。到期或停用后的管理权限以平台提示为准，恢复授权后重新检查节点与业务。组织试用不会因备份恢复、重装或后接节点重新开始。
