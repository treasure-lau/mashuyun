# 可信下载

先登录麻树云，在当前组织“客户节点 → 开始接入”读取批准版本、目标平台、下载地址和 SHA256。此登录平台提供首次核验所需的可信信息；只对照从下载包内得到的摘要，不能建立首次信任。

本页对应 **mashuyun-20261110-r1**，只列出该版发行目录中的制品。安装时应选择与登录平台批准版本一致的文档与节点包。

## 核验顺序

1. 从平台链接下载节点归档与独立验包工具，保留归档原文件。
2. 使用平台展示的命令，核对归档与独立工具的 SHA256。Mac 使用 `shasum -a 256`，Linux 使用 `sha256sum`。
3. 解包到独立目录，将平台命令中的解包路径替换为该目录的规范绝对路径。只运行已与平台可信摘要核对一致的独立工具，执行 `saas-verify-delivery --bundle-root` 检查。
4. 收到 `DELIVERY_VERIFIED` 后，才运行解包目录内的麻树云接入助手或 CLI。摘要或验签失败时保留原材料，重新从当前批准版本下载，不绕过检查。

独立工具会核对签名清单和包内完整文件集合。不要把包内程序当作独立核验来源，不混用其他版本的工具、清单或组件，也不要在核验后单独替换文件。

Mac 图形应用还需要通过系统签名与 Gatekeeper 检查。若系统拦截该应用，请重新核对批准版本和签名发行材料，不要用清除隔离属性等方式绕过检查。
